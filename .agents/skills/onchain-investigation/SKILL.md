# On-chain investigation
Read `methodologies/07-onchain-intelligence-methodology.md`, `methodologies/06-source-provenance-methodology.md` and quality methodology as needed.
1. Pin chain, block range/hash, contract/mint, token decimals, finality, bridge/wrapped identity and classification semantics.
2. Distinguish logs/transfers from exchange inflows, wallet ownership claims, beneficial ownership, intent and wash activity.
3. Record reorg/finality risk, indexer lag, internal transfers, account abstraction and bridge double counts.
4. Corroborate consequential clusters and explain confidence with alternative wallet/flow attribution.
5. Return reproducible queries and uncertainty; never submit on-chain transactions or read wallet holdings without explicit authorization.
