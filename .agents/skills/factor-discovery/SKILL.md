# Factor discovery
Read `methodologies/03-factor-research-methodology.md` and provenance methodology when input lineage is material.
1. State hypothesis, economic mechanism, outcome variable, holding period, benchmark and universe definition before computing.
2. Account for listings, delistings, stale supply, corporate/token events, look-ahead timing, overlapping observations and all attempted variants.
3. Track effect magnitude, distribution, turnover, cost sensitivity, regime variation and multiple-comparison exposure.
4. Distinguish exploratory signal from frozen confirmatory strategy. Hand a fixed specification to `backtest-validation`; no reported alpha without executed OOS evidence.
5. Record null and adverse results instead of selecting only winners.
