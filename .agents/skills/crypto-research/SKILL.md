# Research coordinator
1. Read `AGENTS.md`, `docs/orchestration-contract.md`, and the methodology routing table. Establish question, venue, exact instrument, horizon and allowed data scope.
2. Select domain skills by their distinct purpose; do not preload all methodology files. Use the smallest set sufficient for the question.
3. Acquire source observations; log their original producer, market, units, temporal semantics, availability, retrieval and tool version when accessible. Never imply connectivity from registration.
4. Have the source validator challenge critical data and a different reviewer challenge high-stakes interpretations, if native agents are available. Do not parallelize competing writes.
5. Separate observation, calculation and inference; reconcile disagreement with direct evidence, otherwise downgrade the verdict.
6. Deliver the report contract in `AGENTS.md`; for machine-readable artifacts use `schemas/research-report.schema.json` and document missing coverage.
7. On methodology conflicts do not invent a harmonization; cite competing sections and disclose unresolved choices. No live/paper order placement or account mutations.
